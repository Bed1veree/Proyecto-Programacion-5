# Mockups de la interfaz

Los mockups se hicieron para pensar las pantallas principales antes de terminar todas las funciones. Sirven como guía para la navegación y el contenido de la interfaz en Next.js.

## Pantallas planteadas

1. **Inicio:** muestra una presentación corta del sistema y acceso al catálogo.
2. **Inicio de sesión:** permite entrar con la cuenta de administrador.
3. **Panel de administración:** muestra las solicitudes de préstamo para aprobarlas o rechazarlas.
4. **Catálogo:** permite ver libros y hacer búsquedas.
5. **Detalle de libro:** muestra los datos de un libro y su disponibilidad.

## Ideas de diseño

- La navegación es sencilla y deja visibles las acciones principales.
- La información se agrupa en tarjetas para revisar el panel con facilidad.
- Los mensajes vacíos indican cuando todavía no hay datos para mostrar.
- Las pantallas usan español y una estructura parecida entre sí.

En `docs/mockups/mockups_ascii.txt` están los bocetos en texto. Algunos muestran pantallas que todavía no están implementadas.
